Web dev stuff

Today I learned about some basics of CSS. The basic syntax consists of a selector, and encased in a block of curly braces some properties and the values. The selector types can be elements, classes or id's. Generally, div blocks are used to surround desirable groups of elements which to apply style rules.

It's possible for a same list of properties to apply to different selectors, by separating them with commas. It's also possible to assign different classes to a same element by separating them with spaces. Also, if you wish to match elements having two (or more) classes you use a dot. So for example if an element has a subsection header class, and you have some other element with just the subsection class, you can select the element which has both the subsection and header classes by using the subsection.header selector. If you wish to select class + id, you use the hash symbol instead of the dot.

One can also select elements by describing their ancestors and children. So if we have a div with class ancestor and within it a div with class contents and within it another div with class contents, then both divs within the ancestor scope would be selected and any other element with class contents outside the scope of ancestor would not be selected.

Such selector would be specified as .ancestor .contents.

Oh, and almost forgot! In order to link the CSS file we need to include it on the head section of the html document. In order to include it, you must add the void element link with the href pointing to the .css file and a rel with value stylesheet.

Though you can also add a style tag within the head element, or add inline css by adding the style property to the element, but this is discouraged since it's cleaner to keep css changes to just one place (the file).
