Padding

So, having said that, in the CSS box model padding sits between the border and the content area and is used to push the content away from the border. According to the mdn documentation, any background applied to the element will display behind the padding.

Similarly to margin, the padding can be specified for all of the faces of the CSS box. (top, bottom, left and right). What's more, specifying a negative padding value is the same as specifiying a padding of zero.

The box model and inline boxes

It seems that, as the name implies, inline boxes are those which are placed inline, such as those boxes used for elements like span.

For inline boxes, width, height, and top and bottom margins do not affect the position of the surronding content, though they do affect the size of the inline box (well, only the top and bottom margins affect the size, not the dimensional properties). Only the left and right padding, margins, and borders affect the position of the text surronding the inline box.

The special value inline-block of the display attribute aims to provide a middle ground between inline and block. The general guideline for its use is to use it when one does not want an item to break onto a new line but one does want the box to respect the width and height and avoid overlapping.
