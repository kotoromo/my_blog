Block and Inline

CSS has two box types: inline and block; and they determine element behavior and interaction. The display property controls how HTML elements appear on the webpage.

By default, block elements will appear on the page stacked atop of each other. Inline elements do not start on a new line. They appear in line with whatever elements they are placed beside.

Inline block elements behave like inline elements but with block-style padding and margin. Flexbox is more common to be used than inline block style.

Divs and spans are usually used when there is no semantic need for a particular block (think not a paragraph for example) but for a container to style.

Divs strech across the full width of its parent and starts on a new line by default. Divs are usually used to group related elements inside page components (think sections, sidebars, nav bars, etc.). Perhaps I should've used divs to separate sections instead of whatever I am doing now.

A span is a generic inline container. It takes up as much space as its content. Since this element is inline, it does not start on a new line. Spans are used when one wants to style or target just part of a sentence. So one could go on defining a special style for emphasizing text, or styling particular headers, etc.
